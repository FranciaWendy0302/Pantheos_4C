╔════════════════════════════════════════════════════════════╗
║              FASTEST WAY TO GET ICONS                      ║
╚════════════════════════════════════════════════════════════╝

1. Go to: https://game-icons.net
2. Search for each icon:
   - "backpack" for inventory
   - "shop" for shop
   - "scroll" for quest
   - "gear" for settings
3. Click icon → Download PNG
4. Rename and save to this folder
5. Done! (Takes 5 minutes)
