## How to Convert SVG to PNG (if needed)

### Using Online Tool:
1. Go to: https://cloudconvert.com/svg-to-png
2. Upload SVG file
3. Set size to 128x128
4. Download PNG

### Using GIMP (Free):
1. Open SVG in GIMP
2. Set import size to 128x128
3. File → Export As → PNG

### Using Inkscape (Free):
1. Open SVG in Inkscape
2. File → Export PNG Image
3. Set width/height to 128
4. Export
